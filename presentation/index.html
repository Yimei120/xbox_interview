Technical · Team actions and limitations

Next steps for data science and engineering

Data science

Design a 2 × 2 test: standard vs guided AI onboarding, crossed with holdout vs day-7 prompt. Estimate guidance and prompt lift separately. Size the experiment using future traffic and a predefined useful effect.

Engineering

Implement stable assignment and prompt eligibility. Log AI task exposure, success/error events, and prompt delivery or dismissal with timestamps. Join these events to upgrade and cancellation records.

Data limitations

Only 33 upgrades in synthetic data. User intent, acquisition channel, and prompt exposure are missing. The generator restricts upgrade timing to days 4–45.

Keep existing AI access consistent across test groups. This estimates additional guidance and prompt effects. Estimating the total effect of AI availability requires a different randomized comparison.
5 / 5
Use a signup-time factorial assignment. A=standard onboarding/no extra prompt, B=standard/prompt, C=guided/no extra prompt, D=guided/prompt. Guidance effects: C−A and D−B. Prompt effects: B−A and D−C. Predefine factorial main effects, relevant interaction checks, and multiple-comparison handling. Suggested prompt policy: first eligible session on day7, fallback through day13, only if still Free. Users upgraded before delivery remain in their originally assigned groups for intention-to-treat analysis. Avoid selecting only post-randomization high-engagement users when evaluating guidance. The baseline includes existing AI access and any existing standard messaging, so do not call it “no AI.” Keep pricing consistent. Engineering: record assignment before exposure, UTC event timestamps and signup-relative age, attempt IDs, feature identity, task outcomes, prompt eligibility and reasons for exclusion, delivery and dismissal, and billing transitions. Distinguish zero activity from missing telemetry. Data science: later validate any targeting model on a larger future cohort, with calibration and incremental value beyond baseline engagement. All feature-level comparisons are exploratory, and only 33 events limit model complexity and precision.
